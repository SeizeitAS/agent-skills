# Public repository: general procedures only, nothing from the private repositories

The owner made this repository public (2026-11-20) so the skills can help others building on Midnight.
Two of the source repositories are private, and Business 20 is proprietary. A skill therefore describes a
general procedure, for example "anchor closed price windows as a Merkle root", and never carries code,
schemas, data, internal URLs or network details from a private repository. Every push is scanned
(`secret-hygiene`, locally and in CI). Skills that can only be written with Business 20 content need the
owner's ok and may live in a separate private repository.
